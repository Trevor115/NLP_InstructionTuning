# NLP_InstructionTuning

# Reflection
Why do base models struggle to follow instructions?
- Base models are trained to predict the next word, not specifically to follow directions. They may understand the prompt but not always respond in the desired format.

How does instruction tuning improve performance?
- Instruction tuning teaches the model how to respond to different types of requests by using examples which makes it better at following instructions.

Why do examples help guide the model?
- Examples show the model the expected pattern and format. The model can then copy that pattern when generating its' response.

Why can models still fail even after instruction tuning?
- Instruction tuning improves behavior, but it doesn't guarantee correct answers. The model can still make mistakes in reasoning, counting, or understanding complex tasks.

Do you think this process creates true understanding?
- Not true understanding. The model learns patterns from data and examples, but it doesn't think or understand information the way humans do.
